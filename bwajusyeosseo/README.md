# 봐주셨어 (Bwajusyeosseo)
등하원·돌봄 이모님을 플랫폼 없이 직접 고용한 가정을 위한 근무시간·급여 장부. 원탭 도착/퇴근 기록, 우리집 계약 규칙(분할 근무·짧은 차이 무시 기준·부모 사정 취소 시 지급·공휴일·추가 업무 단가)대로 월 정산서 자동 계산, 이모님과 공유하는 정산 이미지. 오프라인 완결, AI 없음.
- index.html — 전 화면 한 페이지
- home.html — 오늘 (등원/하원 구간 원탭, 계약 대비 차이, 이번 달 예상 급여, 주간 출근 현황)
- settle.html — 10월 정산서 (기본/연장/추가 업무/차감 내역 + 근거 날짜, 이모님에게 보내기)
- rules.html — 우리집 계약 규칙 (시급, 요일·구간, 짧은 차이 무시, 취소 사유별 지급, 공휴일, 추가 업무 단가)
