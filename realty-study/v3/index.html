우리집 찾기 · v3 시안

집공부(학습·청약) → 실전 매수용으로 개편. 탭 3개: 매물 / 임장 / 요청. 핵심 흐름은 매물 담기 → 임장 체크 → '별로'를 조건으로 → 매물 다시 거르기.

1. 매물 탭 + 조건 편집 시트필수 4조건(8억 미만·여의도 60분·주차·아파트) 고정 + 임장에서 추가한 조건 토글. 단지 카드에 통근·역·주차·세대수 한 줄, 매물별 가격·KB 대비·예산 판정·담기 2. 임장 탭 + 일정 추가 시트다음 임장(D-day) 히어로 · 다녀온 곳(윤/소 점수, 판정) · 담아둔 후보. 일정 잡을 때 '전화로 물어볼 것' 자동 3. 임장 상세 · 현장 체크 + 조건 추가좋음/보통/별로 3단 빠른 체크, 윤재·소정 각자 기록 + 비교, 메모·사진. '별로' 누르면 바로 조건으로 승격 → 적용 시 매물 수 변화 미리보기 4. 요청 탭 (감자봇 대화)감자 웨딩 건의사항의 채팅 버전. 윤재·소정 둘 다 요청, 매물 첨부해서 질문, 처리 상태(접수/처리 중/완료/보류) 표시
정해야 할 것
· 앱 이름: '우리집 찾기' (대안: 집보러가, 둘의 집)
· 통근 시간 계산: 역 기준 고정값 표 vs 길찾기 API (구현 때 결정)
· 기존 집공부는 그대로 두고 새 앱을 따로 띄움 (데이터는 매물 수집 DB 공유)
