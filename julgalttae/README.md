# 줄갈때 (Julgalttae)
테니스 동호인용 라켓별 스트링 수명 트래커 — 날짜가 아니라 "친 시간"으로 줄 수명을 계산하고(폴리 15~20h / 멀티 30h 등 소재별 기본값), 레슨·게임 후 원탭 기록, 갈 때 된 라켓 알림, 줄 조합(소재·게이지·텐션 lbs·하이브리드) 장부 + 회차별 감 회고 + 엘보 체크. 오프라인 완결, AI 없음.
- index.html — 전 화면 한 페이지
- home.html — 라켓별 줄 수명 게이지(남은 시간/예상 교체일), 이번 달 친 시간·줄값
- record.html — 오늘 친 기록 바텀시트 (라켓 선택, 레슨/게임/랠리, 시간 퀵칩, 감·팔 상태)
- racket.html — 라켓 상세: 현재 줄 세팅, 감 변화 곡선, 지난 조합 장부(평점·수명·비용), "이 세팅 그대로 다시 매기" 샵 카드
