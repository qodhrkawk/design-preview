# 또그거 (TtoGeugeo) — 기획서

> **한줄 설명:** "그거 어떻게 했더라?" 를 없애주는 AI 개인 라이프 런북.
> 귀찮은 일을 한 번 해결하면, AI가 그 과정을 깔끔한 재사용 단계로 정리해두고
> 다음에 똑같은 상황이 오면 "너 이거 전에 해봤어" 하고 꺼내준다.

## 1. 문제 정의
사람들은 1년에 몇 번씩만 하는 귀찮은 일들(공유기 초기화, 연말정산 간소화 자료 받기,
프린터 토너 교체, 비자 서류 갱신, 보일러 외출모드 설정, 특정 사이트 환불 절차 등)을
매번 처음부터 헤맨다. 검색해도 내 환경과 안 맞고, 메모앱에 적어둬도
어디 적었는지 못 찾는다. **"분명히 전에 했는데 어떻게 했는지 기억이 안 남"** 이 핵심 통증.

## 2. 타겟 유저
- 1차: 혼자 사는 자취/1인 가구, 집안일·행정처리를 직접 다 챙겨야 하는 사람
- 2차: 작은 사업/프리랜서 — 반복되는 행정·세무·도구 셋업을 매번 다시 검색하는 사람
- 공통: 메모앱에 적긴 하는데 정리가 안 돼서 다시 못 찾는 사람

## 3. 핵심 기능 (MVP)
1. **빠른 기록** — 일 끝나고 한 줄~몇 줄로 "방금 뭘 했는지" 막 적기 (음성 입력 OK)
2. **AI 단계화** — 막 적은 메모를 AI가 깔끔한 번호 매긴 재사용 단계 + 준비물 + 주의점으로 변환
3. **상황 트리거 매칭** — 새 기록/검색 시 "이거 전에 해봤던 그거랑 비슷해" 자동 매칭해서 꺼내줌
4. **다음에 또 알림** — "다음에 이거 또 할 때 알려줘" 설정 시 주기/조건 리마인드 (연 1회 등)
5. **개인 사전화** — 내가 쌓은 런북이 검색 가능한 나만의 "라이프 매뉴얼"이 됨

## 4. 차별점 (왜 대형 서비스가 안 하고, 인디가 유리한가)
- 메모앱(노션/애플노트)은 **정리를 사람이 해야** 함 → 결국 안 함. 여기선 AI가 단계화까지.
- 위키하우/유튜브는 **남의 환경** 기준 → 내 집·내 기기·내 계정 맥락이 빠짐. 여긴 내 기록.
- 토스/네이버 같은 대형은 "1년에 몇 번 쓰는 니치 기억 도구"에 리소스 안 씀 (DAU 안 나옴).
- 인디 강점: 외부 연동 없이 로컬+온디바이스로 시작 가능, 개인화·니치 타겟·프라이버시 강조.
- 리텐션: 쓸수록 내 런북이 쌓여 lock-in. "내 매뉴얼"이라 옮겨갈 이유 없음.

## 5. MVP 범위
### Phase 1 (1-2주, MVP)
- 텍스트 기록 + AI 단계화(번호 단계/준비물/주의점)
- 런북 리스트 + 상세 보기 + 검색
- 태그/카테고리 자동 분류 (집/행정/기기/금융 등)
- 로컬 저장 (오프라인 우선)

### Phase 2
- 음성 입력 → 자동 단계화
- "다음에 또" 주기 리마인드 (연/분기/조건)
- 유사 상황 자동 매칭 ("이거 전에 해봤어")
- 사진 첨부 (모델명, 영수증, 화면 캡처)
- iCloud/구글 동기화, 위젯

## 6. 기술 스택 제안
- **앱:** React Native (Expo) — iOS/Android 동시
- **로컬 DB:** SQLite (expo-sqlite) — 오프라인 우선
- **AI:** 단계화/매칭은 LLM API (gpt-4o-mini 급) — 온디바이스 폴백 고려
- **동기화(P2):** iCloud / Supabase
- **수익화:** 무료(런북 N개 제한) + 월 구독(무제한 + 음성 + 동기화 + 리마인드)
