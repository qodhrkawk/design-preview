# 빌렸어 (Billyeosseo)
우리집 도서관 대출 장부 — 도서관 여러 곳 × 가족 회원증 여러 장의 대출을 한 곳에서. 대출 묶음 단위 반납 D-day(휴관일 반영), 표지 사진으로 "반납 가방" 체크(집안에 흩어진 아이 책 찾기), 회원증별 남은 권수, 도서관별 연체 정지 규칙 계산기. 계정 연동·크롤링 없음, 오프라인 완결, AI 없음.
- index.html — 전 화면 한 페이지
- home.html — 반납 묶음 보드 (D-day, 연장 가능일, 휴관일 경고, 회원증별 권수 요약)
- pack.html — 반납 가방 체크 (표지 그리드 탭 → 가방에 넣음, 못 찾은 책 경고)
- cards.html — 회원증별 대출 현황 + "늦으면 며칠 정지?" 계산기 (도서관 규칙 프리셋)
