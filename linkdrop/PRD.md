# LinkDrop - PRD

## 서비스 개요
링크를 빠르게 저장하고 컬렉션/태그로 정리하는 개인용 북마크 웹앱.

## 타겟 유저
- 나 (개인용)

## 기술 스택
- 프론트엔드: 정적 HTML (MVP) → 추후 React + shadcn/ui
- 저장: localStorage (로그인 없음)
- 메타데이터 추출: 클라이언트 or 무료 API

## MVP 기능
1. 링크 저장 (URL → 제목/썸네일/설명 자동 추출)
2. 컬렉션 (폴더 분류)
3. 태그
4. 검색 (제목/URL/태그)
5. 반응형 (모바일 웹)
6. localStorage 저장

## 안 하는 것
- 로그인/회원가입
- 브라우저 확장
- 공유/소셜
- 하이라이트/메모
- 서버/DB

## 화면
1. 홈 (전체 링크 목록)
2. 컬렉션 뷰 (사이드바/탭)
3. 링크 추가 모달
4. 링크 상세/편집
