# 안샀어 (Woulda) — 한 페이지 기획서

> **AI 안 산 종목 후회 저널 — "살까 말까" 했던 결정을 기록하고, AI가 "그때 샀더라면"을 채점해 매수/매도 감각을 교정한다.**

## 1. 문제 정의
모든 투자 앱은 **실제로 한 거래**만 기록한다. 하지만 투자자를 괴롭히는 건 대부분 **하지 않은 결정**이다 — "그때 살걸", "그때 팔걸". 이 후회는 데이터로 남지 않아서 계속 같은 실수를 반복한다. 매매일지(TradesViz, Tradervue)는 체결된 거래만 본다. 관망·미실행 결정의 결과를 추적하는 도구는 없다.

## 2. 타겟 유저
- 관망/매수타이밍 고민이 많은 개인 투자자 (주식·코인)
- 매매일지는 부담스럽지만 "내가 왜 자꾸 놓치지?"가 궁금한 사람
- 자기 의사결정 패턴을 데이터로 보고 싶은 자기성찰형 (윤재 타입)

## 3. 핵심 기능 (3~5)
1. **관망 결정 기록** — 종목 + "안 샀어/안 팔았어" + 그때 가격 스냅샷 + 이유 + 감정 태그
2. **가상 손익 추적** — 관망가 대비 현재가로 "샀더라면/팔았더라면" 손익을 실시간 계산
3. **AI 채점 리포트** — 월간 결정 점수(캘리브레이션) + 결정별 결과 + 가장 후회된/잘 피한 결정
4. **AI 패턴 분석** — 감정·핑계 멘트별 결과 상관 ("불안할 때 관망은 평균 -18%")
5. **개인화 룰 제안** — 패턴 기반 행동 규칙 자동 생성 ("불안 태그면 24h 뒤 재검토")

## 4. 차별점 (왜 대형 서비스가 안 하는지 / 인디가 유리한지)
- **대형은 안 한다:** 증권사·토스·로빈후드는 "거래를 유도"하는 게 비즈니스다. 사용자에게 FOMO·후회를 보여주는 건 그들의 이해와 충돌. 미실행 결정 추적은 매출에 도움 안 됨.
- **인디가 유리:** 브로커 연동 불필요(관망가 = 사용자가 입력하는 스냅샷 + 공개 시세 1콜). 니치하고 감정적인 주제라 커뮤니티/바이럴("내 후회 점수") 잘 됨.
- **기존 매매일지와 다름:** 체결 거래가 아니라 **counterfactual(반사실) 결정**이 1급 객체.

## 5. MVP 범위
**Phase 1 (1~2주)**
- 관망 결정 CRUD (종목/방향/관망가/이유/감정)
- 공개 시세 1콜로 현재가 → 가상 손익 카드
- 월간 리포트(점수 + 결정별 결과)
- AI 패턴 코멘트 (LLM 1콜)

**Phase 2**
- 알림(관망 N일째 리마인드, 큰 변동 시)
- 개인화 룰 엔진 + 룰 준수 추적
- 결정 점수 공유 카드(이미지), 위젯
- 종목 검색/자동완성, 코인 지원 확대

## 6. 기술 스택 제안
- **앱:** React Native (Expo) — iOS/Android 동시
- **백엔드:** Supabase (Postgres + Auth) — 결정 로그 저장
- **시세:** 무료 공개 시세 API 1종 (현재가만; 코어 가치는 수동 스냅샷으로도 성립)
- **AI:** LLM API (패턴 분석/코멘트/룰 제안) — 월 배치 + 온디맨드
- **수익화:** 무료(결정 N개 제한) + Pro 구독(무제한 + 심화 리포트 + 위젯), 광고 옵션
