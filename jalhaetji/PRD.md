# 잘했어 (Jalhae) — AI 성과 일기

## 한줄 설명
매일 1줄 잘한 일 기록 → AI가 1년 누적해서 자소서·면접·연봉협상용 무기 만들어주는 앱

## 문제 정의
- 직장인/취준생이 자소서·면접·연봉협상 때마다 **"내가 뭘 잘했지?" 기억 안 남**
- 1년치 성과를 막판에 쥐어짜내면 두루뭉술한 추상어만 나옴 ("열심히 했다", "기여했다")
- 노션/베어로 기록해도 분류·요약·STAR 변환은 본인이 해야 함 → 안 함
- 영미권 "Brag Book" 문화는 있지만 한국엔 전용 앱 없음

## 타겟 유저
- **1차:** 이직/연봉협상 준비하는 3-7년차 직장인 (가장 페인 큼)
- **2차:** 자소서 쓰는 취준생/신입
- **3차:** 자기효능감 떨어지는 사람 (자축 일기로 사용)

## 핵심 기능 (MVP 5개)

### 1. 하루 1줄 기록 (홈)
- 매일 저녁 푸시 → "오늘 잘한 것 한 줄?"
- 1줄 입력 (선택: 사진 1장, 음성 30초)
- AI가 즉시 카테고리 자동 태깅 (협업/문제해결/리더십/학습/창의/주도성 등 8개)

### 2. AI 강점 페르소나
- 7일/30일/90일 누적되면 페르소나 카드 생성
- 예: "당신은 **조율형 문제해결자**. 갈등 상황에서 빛납니다"
- 누적될수록 정밀해짐 → 리텐션 핵심

### 3. 자소서 무기고 (Phase 1 핵심 수익)
- 기록 → STAR 형식 자동 변환 (Situation/Task/Action/Result)
- 직무별 필터 ("리더십 관련만", "협업 관련만")
- 복사 → 자소서/이력서에 붙여넣기

### 4. 분기 리포트
- 3개월마다 "이번 분기 당신" PDF/카드 리포트
- 강점 TOP3, 성장 트렌드, 가장 빛난 순간 3개
- 공유 가능 (이력서 첨부 / SNS)

### 5. 연봉협상 준비 모드
- 협상 D-30 입력 시작 → AI가 매일 관련 기록 우선 큐레이션
- D-day에 "협상 카드" 자동 생성 (Quantifiable 성과 위주)

## 차별점

**왜 대형 서비스가 안 하나:**
- 노션/베어: 범용 → 분류·요약 본인 부담
- 잡코리아/사람인: 자소서 시점에만 쓰는 도구, 일상 누적 없음
- 토스·뱅크샐러드: 금융 영역, 자기관리 안 함
- 챗GPT: 누적·구조화·푸시·리텐션 없음

**인디가 유리:**
- 매일 1줄 = 1분도 안 걸리는 마찰 최소화 UX
- AI 분류·페르소나 = LLM 시대에 인디도 가능
- 1년치 데이터 = 진입장벽 (먼저 시작한 유저가 락인)
- 니치: "성과 기록"이라는 단일 가치 → 마케팅 명확

## MVP 범위

**Phase 1 (2주):**
- 하루 1줄 기록 + AI 자동 태깅
- 강점 페르소나 카드 (7일/30일)
- STAR 변환 (단건)
- 무료 + 자소서 변환 월 5회 무료

**Phase 2 (+1주):**
- 분기 리포트 PDF
- 연봉협상 모드
- 프리미엄 (월 4,900원): 무제한 STAR 변환, 분기 리포트, 음성 입력

## 수익화
- 프리미엄 구독 4,900원/월
- 자소서 시즌 (9-10월, 3월) 캠페인
- 광고 X (개인적 데이터라 부적합)

## 기술 스택
- **앱:** React Native (Expo)
- **백엔드:** Supabase (auth + DB)
- **AI:** Claude Haiku (태깅·STAR 변환·페르소나)
- **푸시:** Expo Notifications
- **결제:** RevenueCat
